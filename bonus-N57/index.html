YouTube企画リサーチAI社員

YouTubeの企画出しと競合リサーチをする。届けたい相手の検索語で伸びている動画を自分で集め（Web検索。yt-dlpやYouTube APIがあれば正確な数字）、再生数÷登録者数などで「伸びている」を判定し、企画10本を採点してタイトル案（10の型）と選ぶ1本を出す。

この特典の進め方

上から順に進めます。AIは下書きと候補を出します。どれを使うか、どこを直すかはあなたが決めます。

最初のゴール（今日やる1つ）

AI社員に1回話しかけて、自分のチャンネルの話で返事が返ってくる状態にする。

入れ方

上のボタンから zip をダウンロードします。中身は yt-dept-planning というフォルダ1つです。

  • YouTube企画リサーチAI社員（yt-dept-planning.zip）: YouTubeの企画出しと競合リサーチをする。届けたい相手の検索語で伸びている動画を自分で集め（Web検索。yt-dlpやYouTube APIがあれば正確な数字）、再生数÷登録者数などで「伸びている」を判定し、企画10本を採点してタイトル案（10の型）と選ぶ1本を出す。

Claude Code を使っている場合

  1. ダウンロードした zip を、自分のパソコンの ~/.claude/skills/ に展開します。ターミナルなら次の1行です
unzip ~/Downloads/yt-dept-planning.zip -d ~/.claude/skills/
  1. Claude Code を開き直して、/yt-dept-planning と打って候補に出れば準備完了です

claude.ai（ブラウザ・アプリ）を使っている場合

  1. claude.ai の設定画面を開き、Skills の項目を探します
  2. ダウンロードした zip を、展開せずにそのままアップロードします
  3. 新しいチャットで話しかけます

Skills が使えるプランや画面の名前は変わることがあります。見つからないときは、Claude の公式ヘルプで「Skills」を検索してください。

1分の動作確認

「届けたい相手は『副業で動画を始めたい会社員』です。企画を10本出して」のように話しかけます。足りない情報があれば、AI社員の方から質問が返ってきます。質問が返ってくれば動いています。

zip の中身

AI社員1人は、判断の基準・型・手順・完成見本でできています。このAI社員の中身は次のとおりです。

中身 ファイル 何が入っているか
ワークフロー SKILL.md いつ使うか・手順・各手順の判断基準・出力の型・してはいけないこと
正しいアウトプット（完成見本） references/good-output.md 実際の企画出しを一般化した完成見本（チャンネル名・数値は伏せてある）
ナレッジ（考え方・判断の基準） references/knowledge.md 迷ったときに立ち返る考え方と、優先順位
リファレンス references/competitor-list-template.md 競合リスト（空の雛形）
リファレンス references/planning-criteria.md 企画の判断基準
リファレンス references/research-method.md リサーチの方法（材料を自分で集める）
リファレンス references/title-patterns.md タイトルの型（10個）
リファレンス references/video-formats.md 企画の型（8個）

出力の形は「正しいアウトプット」（完成見本）にそろえて出てきます。見本と並べて、どこを直すかを決めてください。

output/ には、このAI社員を、わどのYouTubeチャンネル「わどAIマネタイズ」の材料で実際に動かした成果物が入っています（競合のチャンネル名・数字は伏せています）。どんな形で返ってくるかを、使う前に見られます。

このあと届くAI社員

企画リサーチAI社員は、YouTube部署の1人目です。次の場面で、AI社員がさらに増えます。

  • セミナー用オープンチャットに参加: YouTube分析AI社員・YouTube公開前チェックAI社員
  • セミナーに参加: YouTube台本AI社員・YouTubeサムネAI社員・YouTube編集AI社員（セミナーの実演で使う3人）

企画の次は台本、台本の次はサムネと編集。工程ごとに担当を分けておくと、毎回ゼロから説明し直さずに済みます。

もう1つの特典: いまの段階を10問で確かめる

LINE登録特典には「YouTube 0→100ロードマップ 現在地診断」も入っています。10問に「はい・いいえ」で答えると、いまの段階と次にやる1つが分かります。

現在地診断を開く

まだジャンルを決めていない人は、「YouTube 今伸びているジャンル一覧＋選び方」で候補を3つに絞ってから、このAI社員に渡してください（ジャンル一覧を開く）。

最新AIが出たときの使い方

AI社員の指示文は、特定のモデルに合わせて書いていません。新しいモデルが出ても、手順はそのままで使えます。モデルの名前・料金・使える範囲は変わるので、使う前に各社の公式サイトで確かめてください。モデルの差より、どの1本のどこを直すかで結果が変わります。

AIに任せる所／自分で決める所

  • AIに任せる所: 候補を出す・下書きを作る・抜けを見つける
  • 自分で決める所: 誰に届けるか、どの案を使うか、数字や実績として何を出すか

AIは数字や実績を作りません。出したい実績は、自分で出典を確かめてから渡してください。
