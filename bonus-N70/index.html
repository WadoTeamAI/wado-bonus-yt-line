YouTube概要欄・導線AI社員

YouTube動画1本の概要欄（最初の2行・本文・チャプター・ハッシュタグ）、固定コメント、終了画面とカードの文言、次に見る動画を、送り先を1つに絞って作る。1本目の動画からこの1体だけで使える。

この特典の進め方

上から順に進めます。AIは下書きと候補を出します。どれを使うか、どこを直すかはあなたが決めます。

最初のゴール（今日やる1つ）

AI社員に1回話しかけて、自分のチャンネルの話で返事が返ってくる状態にする。

入れ方

上のボタンから zip をダウンロードします。中身は yt-dept-funnel というフォルダ1つです。

  • YouTube概要欄・導線AI社員（yt-dept-funnel.zip）: YouTube動画1本の概要欄（最初の2行・本文・チャプター・ハッシュタグ）、固定コメント、終了画面とカードの文言、次に見る動画を、送り先を1つに絞って作る。1本目の動画からこの1体だけで使える。

Claude Code を使っている場合

  1. ダウンロードした zip を、自分のパソコンの ~/.claude/skills/ に展開します。ターミナルなら次の1行です
unzip ~/Downloads/yt-dept-funnel.zip -d ~/.claude/skills/
  1. Claude Code を開き直して、/yt-dept-funnel と打って候補に出れば準備完了です

claude.ai（ブラウザ・アプリ）を使っている場合

  1. claude.ai の設定画面を開き、Skills の項目を探します
  2. ダウンロードした zip を、展開せずにそのままアップロードします
  3. 新しいチャットで話しかけます

Skills が使えるプランや画面の名前は変わることがあります。見つからないときは、Claude の公式ヘルプで「Skills」を検索してください。

1分の動作確認

「この動画の概要欄と固定コメントを作って。送り先はLINE登録（タイトルと台本の要点を貼る）」のように話しかけます。足りない情報があれば、AI社員の方から質問が返ってきます。質問が返ってくれば動いています。

zip の中身

AI社員1人は、判断の基準・型・手順・完成見本でできています。このAI社員の中身は次のとおりです。

中身 ファイル 何が入っているか
ワークフロー SKILL.md いつ使うか・手順・各手順の判断基準・出力の型・してはいけないこと
正しいアウトプット（完成見本） references/good-output.md 動画1本の概要欄と導線を一般化した完成見本（チャンネル名・URL・数値は伏せてある）
ナレッジ（考え方・判断の基準） references/knowledge.md 迷ったときに立ち返る考え方と、優先順位
リファレンス references/description-patterns.md 概要欄・最初の2行・固定コメントの型
リファレンス references/funnel-patterns.md 送り先別の導線の型と、終了画面・カードの置き方
リファレンス references/youtube-specs.md YouTube公式の仕様（導線に関係する所だけ）

出力の形は「正しいアウトプット」（完成見本）にそろえて出てきます。見本と並べて、どこを直すかを決めてください。

output/ には、このAI社員を実際のYouTubeチャンネルの材料で動かした成果物が入っています（競合のチャンネル名・数字は伏せています）。どんな形で返ってくるかを、使う前に見られます。

最新AIが出たときの使い方

AI社員の指示文は、特定のモデルに合わせて書いていません。新しいモデルが出ても、手順はそのままで使えます。モデルの名前・料金・使える範囲は変わるので、使う前に各社の公式サイトで確かめてください。モデルの差より、どの1本のどこを直すかで結果が変わります。

AIに任せる所／自分で決める所

  • AIに任せる所: 候補を出す・下書きを作る・抜けを見つける
  • 自分で決める所: 誰に届けるか、どの案を使うか、数字や実績として何を出すか

AIは数字や実績を作りません。出したい実績は、自分で出典を確かめてから渡してください。
